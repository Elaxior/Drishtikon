# drishtikon

drishtikon is a full-stack hackathon project that helps users search a news topic and (in later parts) compare coverage from multiple sources to identify consensus and disagreement.

This repository now includes:
- Part 1 foundation (health check, frontend-backend connectivity, modular structure)
- Part 2 NewsData.io integration via backend `/search` endpoint

## Tech Stack

### Frontend
- React 19 + Vite + TypeScript
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- FastAPI
- Uvicorn
- python-dotenv
- Requests
- Pydantic

## Environment Setup

Create `backend/.env`:

```env
NEWSDATA_API_KEY=your_key_here
```

Optional environment variables:

```env
FRONTEND_ORIGIN=http://localhost:5173
NEWSDATA_BASE_URL=https://newsdata.io/api/1
NEWSDATA_TIMEOUT_SECONDS=10
NEWSDATA_PAGE_SIZE=10
```

`NEWSDATA_PAGE_SIZE` is capped to a max of 12 to help prevent unnecessary API credit usage.

## Run Instructions

## 1) Run Backend

```bash
cd backend
python -m venv .venv
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
```

Backend runs at: `http://localhost:8000`

Health check: `http://localhost:8000/health`

## 2) Run Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs at: `http://localhost:5173`

## API Endpoints

### `GET /health`

Returns:

```json
{ "status": "ok" }
```

### `GET /search?q=<topic>`

Searches NewsData.io `/latest` for English world/politics coverage and returns a cleaned response.

Example:

```text
http://localhost:8000/search?q=india
```

Response shape:

```json
{
	"query": "india",
	"articles": [
		{
			"title": "...",
			"description": "...",
			"source": "...",
			"link": "...",
			"pubDate": "..."
		}
	]
}
```

## Frontend-Backend Flow

- Frontend calls backend `/search` through `frontend/src/lib/api.ts`
- Backend calls NewsData.io `/latest` with:
	- `apikey`
	- `q`
	- `language=en`
	- `category=world,politics`
	- `size=10` (configurable, hard-capped to max 12)
- Backend normalizes provider data before returning it to the frontend
